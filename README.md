# JavaScript-Course

A collection of interactive web applications and responsive designs developed during my intensive software development bootcamp. This repository showcases my transition from foundational theory to practical, full-stack implementation.

## 🚀 Projects Overview

* **Portfolio Website:** A custom-built, responsive site featuring a video background, smooth scroll navigation, and a dynamic contact form.
* **Tic-Tac-Toe Game:** A JavaScript-driven logic game demonstrating state management and DOM manipulation.
* **Interactive Calculator:** A functional tool focused on mathematical algorithms and CSS grid layouts.
* **Pizza Menu:** A stylized menu project emphasizing structured data and advanced CSS styling.

## 🛠️ Technical Skillset

* **HTML5:** Semantic structuring and SEO-friendly layouts.
* **CSS3:** Advanced styling, animations, media queries, and "Red Theme" customization.
* **JavaScript (ES6+):** Event handling, API interaction, and functional programming.
* **Tools:** Git/GitHub for version control, VS Code, and Chrome Developer Tools for debugging.

## 💡 Key Learning Outcomes

> "The computer programmer is a creator of universes..." — Joseph Weizenbaum

This course emphasized the "learn by doing" philosophy. By building applications from the ground up, I developed a robust workflow for:
1.  **Problem Solving:** Breaking complex features into manageable coding tasks.
2.  **Debugging:** Utilizing console logging and inspector tools to resolve logic errors.
3.  **UI/UX Design:** Creating seamless, interactive user experiences.
